# CONTENT_GUIDE.md

## Objetivo

Este documento guía el contenido de `thayspostres` para mantener una comunicación dulce, clara, artesanal y profesional sin inventar datos reales.

## Tono de voz

Usar un tono:

- Cálido.
- Cercano.
- Dulce.
- Claro.
- Femenino sin exageración.
- Artesanal.
- Moderno.
- Confiable.

Evitar frases genéricas como:

- “La mejor calidad al mejor precio”.
- “Entrega garantizada”.
- “Compra ahora”.
- “Pedido confirmado”.
- “Stock disponible”.

## Uso de `[SUPUESTO]`

Usa `[SUPUESTO]` en productos, categorías o servicios que todavía no estén confirmados.

Ejemplos:

- Pastel personalizado [SUPUESTO]
- Galletas decoradas [SUPUESTO]
- Mesas dulces [SUPUESTO]

## Uso de `[SUPUESTO A VALIDAR]`

Usa `[SUPUESTO A VALIDAR]` para datos comerciales no confirmados.

Ejemplos:

- Teléfono.
- Dirección exacta.
- Horarios.
- Delivery.
- Métodos de pago.
- Redes sociales.
- Dominio final.

## Productos

Cada producto debe redactarse como opción de inspiración o cotización si no está confirmado.

Correcto:

```text
Diseño personalizado según idea, fecha y estilo deseado. [SUPUESTO]
```

Incorrecto:

```text
Pastel de 20 personas por $500 disponible para entrega inmediata.
```

## Precios

No publicar precios sin validación.

No usar:

- Desde $...
- Precio final.
- Promoción.
- Descuento.
- Total.
- Pagar.

## Cotización

Usar textos como:

- Agregar a cotización.
- Solicitar cotización.
- Consultar este producto.
- Enviar selección por WhatsApp.
- Revisar opciones.

Evitar:

- Comprar.
- Pagar.
- Checkout.
- Finalizar compra.
- Pedido confirmado.

## Imágenes

Mientras no existan fotos reales:

- Usar placeholders locales.
- Mantener estética rosa/pastel.
- No usar imágenes externas sin control.
- Reemplazar cuando existan fotografías finales.

## WhatsApp

El mensaje debe ser claro, amable y no debe confirmar pedido.

Debe incluir:

- Productos.
- Cantidades.
- Categoría.
- Tipo de evento opcional.
- Fecha tentativa opcional.
- Notas opcionales.

## FAQ

Las respuestas deben ser prudentes y no afirmar políticas no confirmadas.

Ejemplo seguro:

```text
La disponibilidad y los detalles se confirman por WhatsApp.
```

Ejemplo no permitido:

```text
Entregamos todos los días de 9 a 6 en toda la ciudad.
```
